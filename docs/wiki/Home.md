# ApexSenseBridge for Linux wiki

A Linux command-line bridge based on [ReynArts/ApexSenseBridge](https://github.com/ReynArts/ApexSenseBridge).

- [Controller protocol](Controller-Protocol): V1/V2/V3 framing, identification,
  input, adaptive triggers, rumble, RGB and cleanup.
- [README and setup](https://github.com/RafaelDiasCampos/ApexSenseBridge-Linux#readme)
- [Model support](https://github.com/RafaelDiasCampos/ApexSenseBridge-Linux/blob/main/docs/linux-models.md)

The user has tested the Linux port on an **Apex 5 in Overwatch and Warframe**.
Other model paths have automated coverage and still need physical validation.

Wiki source is versioned in [docs/wiki](https://github.com/RafaelDiasCampos/ApexSenseBridge-Linux/tree/main/docs/wiki).
